## 💻 Run Locally

### Prerequisites

- Node.js and npm
- Git

### Installation

Clone this repository:

```bash
git clone https://github.com/Satya167hub/Portfolio.git
cd Portfolio
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local address displayed in your terminal.

### Production Build

```bash
npm run build
```

The production build is generated in the `dist` directory.
